# Справочник инсайтов проекта «Блог по этикету»

Единая точка входа. Каждый значимый вывод живёт отдельным MD-файлом в папке `insights/`
этого репозитория, здесь — только оглавление с одной строкой сути.

**Правило:** инсайт попадает сюда только с указанием источника данных, даты и статуса
(подтверждено / гипотеза); источник данных указывается в шапке самого файла-инсайта.
Формулировки без цифр и без источника в справочник не берутся.

## Методические правила, добытые кровью

Полностью — в `insights/codebook-dzen.md` (⏳ ещё не перенесён), разделы 2, 3, 5. Коротко:

1. Только доли и индексы, никаких абсолютных лайков и просмотров в сравнениях.
2. Медианы, не средние: один вирусный материал ломает любое среднее.
3. Разметка текстов делается **вслепую**, до соединения с метриками, в случайном порядке.
4. Группа меньше 10 публикаций — вывод не формулируется.
5. Каждая находка предъявляет контрпримеры и проверяется на устойчивость.
6. Признаки проверяются отдельно до и после октября 2025 (граница обвала).
7. Первичный показатель успеха — дочитывания, а не CTR.
