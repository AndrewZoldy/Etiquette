# Справочник: как получить данные Дзена без браузера

**Дата:** 26 июля 2026
**Источник:** прямые запросы к Дзену с локальной машины (Windows, Claude Code), проверено на живых данных 26.07.2026.
**Статус:** подтверждено, работает.

---

## Зачем этот документ

В старом окружении (Claude Code on the web) исходящая сеть была закрыта, и единственным путём к Дзену
считался браузер Валентины или Андрея с расширением Claude in Chrome. Ленту канала приходилось
прокручивать вручную, чтобы собрать ссылки на статьи.

С локальной машины **браузер не нужен**: Дзен отдаёт всё необходимое через свои же внутренние API,
включая полные тексты статей и комментарии. Это снимает главное узкое место проекта.

## Что откуда берётся

| Что нужно | Откуда | Как |
|---|---|---|
| Все публикации канала | `GET https://dzen.ru/api/v3/launcher/export?channel_name=valentinahli` | В ответе `items` (карточки) и `more.link` — следующая страница. Идти по `more.link` до конца: 620 статей за 55 страниц. В `tabs` — отдельные ленты по типам (`article`, `short_video`, `long_video`, `suite`) |
| Заголовок, обложка, лайки, комментарии, дата | карточка из `items` | `title`, `image` (URL обложки), `socialInfo.likesCount`, `socialInfo.commentCount`, `views` (= «Открытия» в Студии), `publication_date`, `publication_object_id` — это id публикации |
| **Полный текст статьи** | HTML страницы `https://dzen.ru/a/<короткий_код>` | Текст отдаётся в серверных данных страницы: `publishersResponse → … → publication.content.articleContent.contentState`. Это JSON-строка, внутри `draftJsState.blocks` — абзацы, подзаголовки, цитаты, списки |
| **Все иллюстрации внутри статьи** | те же `blocks` | Блоки с типом `atomic:image` и полем `data.image.id`. URL картинки собирается как `https://avatars.dzeninfra.ru/get-zen_doc/271828/pub_<id_публикации>_<id_картинки>/<размер>`. Размеры: `scale_1200`, `scale_2400`, `smart_crop_500x500` |
| **Комментарии, включая ответы** | `GET https://dzen.ru/api/comments/v2/root-comments` и `.../child-comments` | Параметры: `documentId=native:<id_публикации>`, `publicationPublisherId=63dd27aac30ab522dcce48b3`, `sorting=oldest\|newest\|top`, `batchSize` (корневые — максимум 50, ответы — 20), `withConfig=true`. Ответы к комментарию: `child-comments` с `rootCommentId` |
| Лайки/дизлайки/статус комментария | тот же ответ, блок `metaByCommentId` | `likes`, `dislikes`, `childrenCount`, `isPinned`, `state`, `publicationChannelOwnerReaction` |
| Автор комментария | блок `usersById` по `authorUid` | `displayName`, `publisher.name` (если у автора есть свой канал) |

Пагинация комментариев — через поле `moreItemsQueryString` в ответе: его нужно подставить как строку
запроса к тому же методу.

## Ключ для склейки со статистикой Студии

**Гиперссылки в колонке «Ссылка» выгрузки Студии содержат id публикации:**
`https://dzen.ru/media/id/63dd27aac30ab522dcce48b3/<id_публикации>`.

В самой ячейке видно только слово «ссылка», поэтому при чтении файла нужно брать не значение ячейки,
а адрес гиперссылки (в Python — `openpyxl`, свойство `cell.hyperlink.target`).

Это даёт **точную склейку** статистики Студии с собранными текстами и комментариями — без сопоставления
по заголовкам, которое неизбежно ошибается на похожих названиях. Проверено: из 623 статей Студии
620 сошлись с публичными карточками по id, три несошедшихся — публикации с нулевыми показами.

## Технические детали, на которых легко спотыкнуться

1. **Первый запрос к `dzen.ru` уходит в редирект на SSO Яндекса.** Нужна сессия с приёмом cookies:
   сделать один «прогревочный» запрос на `https://dzen.ru/`, дальше всё работает. Авторизация не требуется —
   всё перечисленное доступно без входа в аккаунт.
2. **Проверка SSL-сертификата может падать** на некоторых машинах при обращении к серверам Яндекса.
3. **`batchSize` больше разрешённого даёт HTTP 400.** Для корневых комментариев максимум 50, для ответов 20.
4. **Публичные «просмотры» в карточке — это «Открытия» Студии**, а не показы (см. `2026-07-25-bazovye-orientiry.md`).
5. **Обложка статьи — это, как правило, первая картинка в теле статьи**, тот же id изображения.
6. Страница статьи весит около 1,1 МБ; 620 статей качаются примерно за 12 минут в 5 потоков.

## Что этим собрано 26.07.2026

- 620 публичных карточек статей
- 620 полных текстов (медиана около 500 слов)
- 3 138 иллюстраций в теле статей (медиана 4 на статью, максимум 14) + 620 обложек
- комментарии по всем статьям, где они есть (549 статей)

## Что по-прежнему требует Студии (то есть браузера Валентины)

Непубличная статистика: показы, дочитывания, время просмотра, подписки, источники трафика,
уведомления платформы и статус канала. Всё это выгружается вручную:
Дзен-Студия → Статистика → Публикации → период «Всё время» → «Отчёт».
