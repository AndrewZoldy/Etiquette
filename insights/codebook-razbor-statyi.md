# Справочник: правила разбора одной статьи

**Версия:** 1.0 · **Дата:** 26 июля 2026
**Назначение:** инструкция для помощника, который разбирает **одну** статью целиком —
текст, обложку, все иллюстрации в их местах и все комментарии. Один помощник = одна статья.

---

## 1. Принципы

1. **Разбор слепой.** Помощник не видит показов, дочитываний, CTR и подписок. Он не должен
   их угадывать и не должен подстраивать оценки под «похоже, это была успешная статья».
   Числа лайков и комментариев он видит — они часть материала, но выводы о раздаче делать нельзя.
2. **Только то, что есть в материале.** Если признака нет — «нет». Если определить нельзя —
   «не определить». Выдумывать нельзя ничего, включая цитаты.
3. **Цитаты дословно.** Речевые обороты, реплики комментаторов, формулировки претензий —
   копируются буквально, без пересказа и без правки орфографии.
4. **Иллюстрация оценивается по своему месту.** Картинка стоит между конкретными абзацами;
   её связь оценивается с этим абзацем, а не только с заголовком.
5. **Разрешение картинок намеренно низкое.** Мелкие детали выискивать не надо, оценивается
   общее впечатление и сюжет.
6. **Числа — целые.** Шкалы 0–3 и 1–5 без дробей.

## 2. Что даётся помощнику

| Материал | Формат |
|---|---|
| Заголовок и полный текст | текст статьи целиком |
| Подзаголовки, число абзацев, число слов | числа |
| Обложка | файл изображения 512px |
| Полотно всех иллюстраций | одна картинка-контактный лист, кадры подписаны номерами |
| Каждый кадр в контексте | абзац до кадра, абзац после, подпись |
| Комментарии | самые залайканные, самые заминусованные, самые свежие, с лайками и ответами |
| Эталоны внешности автора | два файла изображений |

## 3. Поля разбора

### 3.1 Предмет и норма

| Поле | Значения | Пояснение |
|---|---|---|
| `subject` | текст | о каком конкретно правиле статья, одной фразой |
| `situation_frequency` | ежедневно / несколько раз в год / раз в несколько лет / почти никогда | как часто читатель попадает в эту ситуацию |
| `audience` | всем / женщинам / хозяйке / гостю / родителям / работающим / узкой группе | |
| `norm_clear` | да / частично / нет | уходит ли читатель с чётким правилом |
| `norm_disputable` | да / нет | можно ли всерьёз не согласиться |
| `norm_source` | этикет как система / здравый смысл / традиция / мнение автора / заграница / история | на что опирается норма |
| `has_prohibition` | да / нет | статья говорит, чего делать нельзя |
| `cost_to_follow` | ноль / небольшой / заметный | сколько стоит читателю соблюсти правило (деньги, время, неловкость) |

### 3.2 Структура

| Поле | Значения |
|---|---|
| `opening_type` | вопрос / сценка-история / провокация / определение / цифра-факт / обращение к читателю / цитата / описание проблемы |
| `hook_strength` | 0–3 |
| `structure` | список / повествование / вопрос-ответ / разбор случая / инструкция / эссе / сравнение до-после / правило и исключения |
| `ending_type` | вывод / вопрос читателю / призыв / смягчение / мораль / резкая точка / оборвано |
| `ending_words` | число слов в последнем абзаце |
| `call_to_comment` | да / нет |
| `internal_link` | да / нет |
| `title_promise_kept` | да / частично / нет |

### 3.3 Голос

| Поле | Значения |
|---|---|
| `tone` | строгий / дружелюбный / ироничный / назидательный / доверительный / снисходительный / нейтрально-справочный |
| `author_stance` | судит / описывает / оправдывает / балансирует |
| `categoricalness` | 0–3 |
| `personal_experience` | да / нет |
| `judged_party` | нет / гости / хозяева / соседи / родня / коллеги / персонал / мужчины / женщины / молодёжь / старшее поколение / иностранцы / сам читатель |

### 3.4 Приёмы и речь

| Поле | Что писать |
|---|---|
| `devices` | список реально использованных: риторический вопрос, антитеза, градация, ирония, парадокс, апелляция к истории, апелляция к загранице, апелляция к авторитету, анекдот, диалог, прямая речь, триада, правило-и-исключение, гипербола, разбор чужой ошибки, самоирония, цитата классика |
| `phrases` | 3–5 характерных оборотов **дословно** |
| `evaluation_words` | слова оценки поведения: моветон, дурной тон, бестактно, невоспитанно… |
| `concrete_examples` | число описанных конкретных ситуаций |
| `numbers_in_text` | да / нет |

### 3.5 Читательский эффект

| Поле | Значения | Пояснение |
|---|---|---|
| `recognisability` | 0–3 | узнаёт ли читатель себя или знакомых |
| `dispute_potential` | 0–3 | захочется ли возразить |
| `novelty` | 0–3 | узнаёт ли читатель что-то новое |
| `hate_risk` | 0–3 | есть ли то, за что автора будут ругать |
| `self_repeat` | да / нет / не определить | похоже ли на переписанную другую статью канала |

### 3.6 Обложка

| Поле | Значения |
|---|---|
| `cover_subject` | что изображено, одной фразой |
| `cover_people` | нет людей / автор одна / автор с мужчиной / автор с женщиной / автор в группе / другие люди / пара / ребёнок |
| `cover_interaction` | 0–3: 0 — портрет или предмет, 1 — люди рядом без контакта, 2 — явное взаимодействие, 3 — конфликт или объятие |
| `cover_link_to_title` | прямая / косвенная / нет связи |
| `cover_emotion` | улыбка / нейтрально / напряжение / негатив / нет лица |
| `cover_source` | авторская съёмка / сток / нейросеть / архив / текстовая карточка |
| `cover_curiosity_gap` | 0–3 | оставляет ли обложка вопрос, который хочется закрыть |

### 3.7 Иллюстрации в местах

| Поле | Значения |
|---|---|
| `frames_total` | число |
| `frames_on_point` | сколько кадров ложатся на свой абзац |
| `frames_off` | сколько не связаны ни с абзацем, ни с заголовком |
| `frames_duplicate` | сколько кадров дублируют друг друга |
| `set_source` | авторская съёмка / сток / нейросеть / архив / смесь |
| `shows_mistake` | да / нет — есть ли кадр с неправильным поведением |
| `set_score` | 1–5 |

### 3.8 Комментарии

| Поле | Что писать |
|---|---|
| `comments_read` | сколько комментариев реально прочитано |
| `reaction_mix` | доли в процентах: поддержка / спор по существу / хейт / личные истории / офтоп / вопросы автору (в сумме 100) |
| `top_comment_type` | что за комментарий собрал больше всего лайков: своя история / возражение / шутка / похвала / уточнение / претензия |
| `hate_themes` | какие именно претензии звучат — из списка ниже, плюс новые если есть |
| `hate_quotes` | 2–4 дословные цитаты претензий с числом лайков |
| `disagreement_subject` | о чём именно спорят (не «о статье», а конкретно) |
| `own_stories` | да / нет — рассказывают ли читатели свои случаи |
| `author_replied` | да / нет |
| `unanswered_questions` | вопросы читателей, оставшиеся без ответа — материал для будущих статей |

**Типовые претензии хейтеров канала** (обнаружены при разборе 60 тысяч комментариев,
список открытый):

- `оторванность` — «в реальной жизни так не бывает», «где вы такое видели»
- `нет_личного_опыта` — «пишет человек, у которого нет дачи / не был в браке»
- `нейросеть` — обвинение в том, что текст написан ИИ
- `вода` — «слов много, толку нет», «можно уложить в одно предложение»
- `устарело` — «правила устарели лет на сто»
- `снобизм` — «не учите жить», «кто вы такая»
- `не_по_деньгам` — «не для наших зарплат»
- `банальность` — «это и так все знают»
- `навязывание` — «кому надо, тот и так делает»

### 3.9 Итог

| Поле | Значения |
|---|---|
| `strength_score` | 1–5: сила статьи как материала для широкой ленты |
| `weaknesses` | перечисление слабых мест |
| `what_worked` | что в этой статье сделано хорошо и стоит повторять |
| `rewrite_headline` | как бы ты переписал заголовок, чтобы он обещал спор, а не справку |
| `comment` | 1–2 предложения по-русски |

## 4. Чего делать нельзя

1. Ставить оценку по ощущению «это популярная тема» — оценивается материал, а не тема.
2. Считать высокий лайк комментария признаком согласия: самые залайканные комментарии
   канала — это чужие истории и возражения, а не похвала.
3. Записывать в хейт вежливое несогласие. Хейт — это претензия к автору, а не к правилу.
4. Пропускать поле. Пустое поле хуже честного «не определить».
5. Дробить результат на несколько файлов. Одна статья — одна запись.
