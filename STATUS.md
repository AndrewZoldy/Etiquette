## Незакрытое: поштучный разбор статей

Разобрано **213 из 620** статей по одному помощнику на статью (полный текст + обложка +
иллюстрации в привязке к абзацам + комментарии, 40+ полей справочника
[`codebook-razbor-statyi.md`](insights/codebook-razbor-statyi.md)).
Находки — в [`insights/2026-07-26-defekty-statey.md`](insights/2026-07-26-defekty-statey.md).

**Две проблемы, которые надо знать при продолжении:**

1. **Разобранные 213 статей — целиком из эпохи «до спада».** Пакеты идут в порядке
   идентификатора публикации, а он содержит метку времени. Поэтому в выборке нет ни одной
   статьи эпохи «дно» и ни одной из серии вт/чт без комментариев. Качественные дефекты
   от эпохи не зависят, но числовые связи по этой выборке строить нельзя.

2. **Ошибка в запуске волн 2 и 3 (исправлена).** Параметр диапазона приходил в скрипт
   строкой, а не объектом, поэтому `args.from` был `undefined` и диапазон молча схлопывался
   в 0–200. Оба запуска переразобрали те же статьи, что и волна 1. В скрипте
   `per-article-wave-wf_d55c7aed-cde.js` теперь добавлен разбор строки:

   ```js
   let A = args
   if (typeof A === 'string') { try { A = JSON.parse(A) } catch (e) { A = null } }
   ```

**Как продолжить:** пересобрать список ещё не разобранных статей и запустить волны заново.

```
# 1. обновить список неразобранных
python -c "import glob,json,os; done={os.path.basename(f)[:-5] for f in glob.glob('out/marks_article/*.json')}; idx=json.load(open('out/bundles/_index.json',encoding='utf-8')); json.dump([r['oid'] for r in idx if r['oid'] not in done], open('out/wave_all.json','w'), ensure_ascii=False)"
# 2. запустить волну (проверив в логе, что диапазон применился)
Workflow({scriptPath: ".../per-article-wave-wf_d55c7aed-cde.js", args: {from: 0, to: 200}})
```

Порядок в `wave_all.json` — по идентификатору, то есть по времени. Чтобы получить сбалансированную
по эпохам выборку, список стоит предварительно перемешать или начать с конца (свежие статьи).

**Лимит сессии** исчерпывался дважды (сбросы в 05:20 и 15:10 по Москве). Результаты
завершённых агентов сохраняются на диск сразу, поэтому ничего не переделывается заново —
но большие волны надо запускать с запасом по лимиту.

## Методические правила, добытые в этой сессии

Дополнение к [`insights/codebook-dzen.md`](insights/codebook-dzen.md):

1. **Выборку, отобранную по результату, нельзя сравнивать с медианой популяции.**
   На стратифицированной выборке индексы дают разницу в 150 раз там, где её нет.
2. **Признаки, коррелирующие с темой, надо проверять внутри темы.** Оценка иллюстраций
   при контроле на тему переворачивается: то, что казалось «декоративное лучше»,
   оказалось «энциклопедические статьи лучше иллюстрированы и хуже раздаются».
3. **Доли вида «X на дочитывание» непригодны для связи с раздачей** — числитель и знаменатель
   растут вместе. Сравнивать надо абсолютные числа внутри полос по дочитываниям.
4. **Ключи JSON-схемы для субагентов должны быть латиницей** — кириллические ключи
   роняют вызов с ошибкой 400. Значения и описания могут быть на русском.
5. **Помощнику нельзя давать больше ~20 полных текстов за раз** — при 45 текстах агенты
   обрывают работу и дробят результат на части.
6. **Каждую выгрузку Студии архивировать.** Вопрос «двигает ли обсуждение раздачу»
   решается только сравнением двух выгрузок с интервалом в месяц.
